TIC-TAC-TOE project
✨ Features
🎮 Two-player Tic Tac Toe gameplay
🖥️ Simple graphical user interface using Java AWT
🔲 Interactive 3×3 game board
❌⭕ Automatic turn switching between Player X and Player O
🏆 Detects winning combinations automatically
🤝 Detects draw when no moves are left
🔄 Automatically resets the board after each game
🖱️ Prevents players from selecting an already occupied cell
💬 Displays winner and draw messages using dialog boxes

🛠️ Technologies Used in This project
#Java
#Java AWT (Abstract Window Toolkit)
#Event Handling (ActionListener & WindowAdapter)
#Object-Oriented Programming (OOP)
#GridLayout for the game board

▶️ How to Run
#Prerequisites
#Java JDK 8 or later installed.
#Steps
##Clone or download this repository.
#Open the project in any Java IDE (VS Code, Eclipse, IntelliJ IDEA, or NetBeans).
#Compile the source file:
#javac TicTacToe.java
#Run the program:
#java TicTacToe
#The Tic Tac Toe game window will open, and two players can start play
